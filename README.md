# 🍎 CalorieTrack

CalorieTrack is a simple and user-friendly **web application for tracking daily calorie intake**. It helps users record food, calculate calories, monitor meals, and review their calorie history.

## 🎯 Objective

To develop a simple web application that helps users **track and manage their daily calorie intake**.

## 💡 Solution

CalorieTrack provides an easy platform where users can search and record food items, calculate consumed calories, track meals, and monitor their daily calorie progress through history and charts.

## ✨ Features

* 🔎 Search and select food items
* 🍽️ Track daily meals
* 🧮 Calculate calorie intake
* 📊 View daily calorie statistics
* 📈 Monitor calorie intake trends
* 📅 Filter calorie history by date
* 🎯 Set and compare daily calorie goals
* 📱 Responsive design for different screen sizes
* 💾 Store tracking data using browser `localStorage`

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and calculations
* **LocalStorage** – Storing calorie and meal data
* **Canvas API** – Calorie history chart
* **Vercel** – Frontend deployment

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser.
4. Start searching for food and recording meals.
5. View your calorie history and progress from the **Track Calories Intake** page.
